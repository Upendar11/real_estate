## 🎬 Animation Patterns

### Pop In (Most Common)
```python
{"pop": 1}  # Character appears with a pop effect
```

### Walk In
```python
(0.0, -100, y, {"o": 1}),  # Start off-screen
(0.5, x, y, {"walk": 1})   # Walk to position
```

### Fade Out
```python
{"o": 0}  # Character fades away
```

### Flip
```python
{"flip": 1}  # Flip horizontally
```

## 💡 Usage Tips

### For Educational Content
1. **Hardware Lessons**: Use CPU, RAM, HDD, monitor, keyboard, mouse together
2. **Transportation**: Show car_blue, truck, bus, airplane in sequence
3. **Nature**: Combine animals like cat, rabbit, butterfly, fish
4. **Size Comparisons**: Use giraffe (tall), elephant (wide), fish (small)

### For Engagement
1. **Color Teaching**: Use the 4 different colored cars
2. **Progression**: Start with bicycle, move to car, then airplane, then rocket
3. **Build Scenes**: Combine laptop, keyboard, mouse on a virtual desk

### For Storytelling
1. **Journey**: Use vehicles to show travel
2. **Tech Lab**: Use all computer components together
3. **Animal Park**: Show multiple animals in one scene
