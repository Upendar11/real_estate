Videogen Toolkit

Sketch-animated, narrated teaching videos: hand-drawn scenes, Pip the penguin host, Asha and Mira story scenes, Piper narration, subtitles, sound effects, music, and a two-pass encode that keeps each video under 30 MB. Used for the CDC, Iceberg, Spark and SQL series.

Set up in a fresh session

  1. Fetch every file below from this artifact into a folder named videogen/, keeping the paths.
  2. Run bash setup.sh. It installs Piper and the ryan-high voice, Playwright, ffmpeg, builds the Excalidraw bundle and renders the sprites.
  3. Edit series.json, write episodes/epNN.py, preview, then render/run_video.sh N.

Smallest episode

from story import *
E = StoryEp(1, "What Is a Row?")
E.intro(["One idea"])
E.story("A question", [("A", "What is a row?", "Asha asks: what is a row?", "think"),
                       ("M", "One record.", "Mira: one record.", "point")])
E.code("A query", "SELECT name FROM customers;", [(1, "Select names.", "Asha · Ben")])
E.hook("One row, one record.", "What is a row?", "One record.", "One record")
E.outro([("Rows are records", "Rows are records.")])
E.build()
